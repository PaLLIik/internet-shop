# TUFF — интернет-магазин на React

Учебный магазин, который строился как демонстрация навыков фронтенд-разработки на React. Товары берутся с [Fake Store API](https://fakestoreapi.com).

## Что умеет

- Каталог товаров с фильтром по категории и поиском по названию. Состояние фильтров хранится в адресе (`/?category=...&q=...`), поэтому ссылку можно открыть или отправить.
- Карточка товара открывается окном поверх страницы: фон размыт, закрывается крестиком, клавишей Esc или кликом по фону.
- Корзина: добавление, уменьшение количества, удаление, итог. Поиск внутри корзины и прокрутка только списка товаров, итог и кнопка оформления всегда на экране.
- Избранное: сердечко на карточках и в карточке товара, отдельная страница со списком, счётчик в шапке.
- Вход и регистрация через окно, токен и пользователь сохраняются между перезагрузками.
- Адаптивная раскладка: сайдбар с категориями, шапка, подвал.

## Стек

- React 19, TypeScript, Vite
- Redux Toolkit и react-redux: товары, корзина, избранное, вход
- React Router 7: маршруты и состояние фильтров в адресе
- Axios: запросы к API через один настроенный клиент (`src/api/client.ts`)
- Vitest, Testing Library: тесты редьюсеров и компонентов

## Запуск

```bash
npm install
npm run dev      # режим разработки, http://localhost:5173
npm run build    # сборка в папку dist
npm test         # тесты
```

## Структура

```
src/
  api/          настроенный axios-клиент
  app/          store и типизированные хуки
  components/   шапка, сайдбар, подвал, карточка товара, окно входа
  features/     срезы Redux: products, cart, favorites, auth (редьюсер + тесты)
  pages/        главная, корзина, избранное, заглушки помощи и условий
  utils/        вспомогательные функции
```

## Решения, которые стоит знать

- **Фильтры в адресе, а не в store.** Категория и поиск — это состояние страницы, которое должно переживать обновление и попадать в ссылки. Поэтому они живут в query-параметрах.
- **Корзина, избранное и вход сохраняются в `localStorage`.** Это подписка на изменения store в одном месте (`src/app/store.ts`). Сохранение обёрнуто в try/catch, чтобы недоступный `localStorage` не ломал приложение.
- **Товары загружаются один раз** в `Layout`, а не в каждой странице.
- **Высота верхнего ряда зафиксирована** переменной `--top-row-height`: баннер и карточка товара одной высоты, без скачков разметки.

## Ограничения

- Fake Store API тестовый: регистрация не создаёт настоящего пользователя, вход работает только с тестовыми аккаунтами.
- У товаров одна картинка, галерея повторяет её. Цвет и размер товара, счётчики покупок в API не приходят, поэтому их нет.
- Токен входа сохраняется в `localStorage`. Для учебного проекта это допустимо, для настоящего магазина нужен серверный сеанс.
